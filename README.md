# HRMS Blueprint (React + Frappe)

This project now contains a modern, responsive product blueprint UI for a complete Human Resources Management System (HRMS).

## Included scope

- Employee lifecycle management (hiring, onboarding, promotions, transfers, exits, retirement)
- Leave and attendance workflows with mobile-friendly interactions
- Expense claims and salary advance approvals
- Payroll and taxation design (salary structures, runs, pay stubs)
- Goal and appraisal based performance management

## Suggested backend stack

- **Python backend:** Frappe Framework
- **Data model:** Frappe DocTypes for employees, leave, payroll, expenses, and appraisals
- **Workflow:** Role-based approvals for HR, managers, finance, and employees

## Run locally

```bash
npm install
npm start
```

Build for production:

```bash
npm run build
```
